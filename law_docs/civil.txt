《民事案例库》

# ==================== 一、民间借贷纠纷（案例1-10） ====================
案例1：原告李某借给王某20000元，双方手写借条，约定1年内还清，到期王某拒不还款。李某向法院起诉，提交借条、微信转账记录。法院认为借贷关系成立，判决王某偿还本金20000元，并支付逾期利息。
案例2：张某向陈某借款5万元，口头约定利息为月息3%，有转账记录，无书面借条。到期张某未还钱。法院认定，约定利率超过合同成立时一年期贷款市场报价利率（LPR）四倍，超出部分利息不予支持，判决返还本金，仅保护法定上限内利息。
案例3：赵某借钱给周某，没有借条，只有微信聊天记录和转账凭证。周某抗辩该款项属于赠与。法院认为聊天记录能够体现借款意思表示，认定借贷关系成立，判令周某归还全部借款。
案例4：刘某借给吴某10万元，约定到期还本付息，吴某只归还部分本金，剩余拖欠。法院判决，未按期还款应当承担逾期利息，逾期利息按照起诉时一年期LPR标准计算。
案例5：杨某向朋友借款3万元，到期无力偿还，双方协商分期还款，后续杨某再次违约。法院认定分期协议有效，杨某再次违约后，债权人可以一次性主张剩余全部欠款。
案例6：夫妻一方在婚姻关系存续期间以个人名义借款，用于家庭共同生活，出借人起诉要求夫妻共同偿还。法院认定该债务属于夫妻共同债务，判决夫妻共同偿还。
案例7：出借人未取得放贷资格，以营利为目的长期向社会不特定对象放贷。法院认定其构成职业放贷，借款合同无效，借款人仅需返还本金，利息不受保护。
案例8：出借人从银行贷款后转贷给借款人牟利，属于套取金融机构贷款转贷。法院认定借款合同无效，借款人返还本金，约定的高额利息不受保护。
案例9：借款时出借人预先扣除利息，借款人实际只拿到部分款项。法院认定本金以实际出借金额为准，预先扣除的利息不计入本金。
案例10：双方借款未约定利息，出借人起诉主张利息。法院认定自然人之间借贷对利息没有约定或者约定不明的，视为没有利息，不予支持。

# ==================== 二、婚约彩礼纠纷（案例11-20） ====================
案例11：甲男与乙女订婚，男方给付彩礼8万元，双方未办理结婚登记，后分手。男方起诉要求返还彩礼。法院依据婚姻家庭编司法解释和涉彩礼规定，判决女方返还大部分彩礼。
案例12：男女双方登记结婚，共同生活仅2个月且未生育子女，男方起诉离婚并主张返还彩礼。法院考虑共同生活时间较短，扣除共同消费开支后，判决女方返还部分彩礼。
案例13：男女双方举办婚礼、长期共同生活，但一直未领证，后感情破裂分手，男方主张返还彩礼。法院考虑双方长期共同生活，酌情减少返还金额。
案例14：恋爱期间男方主动小额转账、发送节日红包，分手后要求全部返还。法院认定该款项属于恋爱期间的赠与，不属于彩礼，驳回返还请求。
案例15：男方给付彩礼后，因自身原因悔婚，要求女方全额退回。法院结合双方过错和实际开销，判决酌情返还部分彩礼，而非全额返还。
案例16：双方已办理结婚登记但确未共同生活，一方离婚时请求返还按照习俗给付的彩礼。法院依法支持返还。
案例17：一方以彩礼为名借婚姻索取财物，另一方要求返还。法院依据涉彩礼规定，支持返还。
案例18：彩礼已实际用于双方共同生活开销的，返还时应扣除已用于共同生活的部分。
案例19：一方在节日、生日等时点给付的价值不大的礼物、礼金，属于为增进感情的赠与，不属于彩礼，分手后不予返还。
案例20：双方对感情破裂均有过错的，法院综合考虑彩礼数额、共同生活时间、双方过错等因素，确定返还比例。

# ==================== 三、劳动纠纷（案例21-30） ====================
案例21：王某在公司上班8个月，单位一直未签订书面劳动合同，并拖欠2个月工资。王某申请劳动仲裁。仲裁裁决：单位支付拖欠工资，同时支付7个月的双倍工资差额。
案例22：企业无正当理由辞退无过错员工。仲裁认定属于违法解除劳动合同，用人单位应支付赔偿金（二倍经济补偿）。
案例23：公司长期不缴纳社会保险，员工以此为由解除劳动合同并申请仲裁。仲裁支持员工，裁决单位支付经济补偿，并补缴社会保险。
案例24：员工离职后，公司拖欠3个月工资拒绝发放。仲裁裁决公司足额支付劳动报酬，劳动者可持调解协议向法院申请支付令。
案例25：员工在试用期被无理由辞退，公司无法举证其不符合录用条件。仲裁认定解除违法，应当支付赔偿金。
案例26：员工在单位连续工作满10年，提出续订无固定期限劳动合同，单位拒绝。仲裁认定单位应当订立无固定期限劳动合同。
案例27：单位安排加班却不支付加班费，员工申请仲裁。仲裁裁决单位依法支付加班费。
案例28：员工工作满3年，劳动合同期满后单位不续签。仲裁裁决单位按每满一年支付一个月工资的标准，支付3个月工资的经济补偿。
案例29：员工违反竞业限制协议，入职竞争对手。仲裁裁决员工支付违约金，并继续履行竞业限制义务。
案例30：劳动关系存续期间单位长期拖欠工资，员工多年后才申请仲裁，单位主张超过一年仲裁时效。仲裁认定劳动关系存续期间拖欠劳动报酬，不受一年仲裁时效限制。

# ==================== 四、合同纠纷（案例31-40） ====================
案例31：甲和乙签订货物买卖合同，甲付全款后，乙方逾期不发货。甲起诉，法院判决乙方继续履行合同交付货物，并赔偿逾期造成的损失。
案例32：商铺租赁合同，承租人提前退租，属于违约。法院判决承租人承担合同约定的违约金，违约金过高的，法院酌情调低。
案例33：网络购物合同，商家收到货款后单方面取消订单。法院认定商家违约，判决退还货款并赔偿消费者的合理损失。
案例34：双方签订服务合同，服务方只完成一半工作，拒绝继续履约。法院判决退还未履行部分的服务费，并承担违约责任。
案例35：房屋买卖意向协议，卖方反悔不卖房。法院判决卖方承担缔约过失责任，赔偿房屋差价等可预见损失。
案例36：借款合同未约定利息，出借人主张利息。法院认定视为没有利息，不予支持。
案例37：合同条款存在两种以上解释，一种解释使条款有效、另一种使条款无效。法院选择有利于条款有效的解释。
案例38：双方签订认购书，约定将来订立正式买卖合同并交付定金，但未签订正式合同。法院认定预约合同成立，违约方承担预约合同责任。
案例39：买卖合同中买方交付定金后，卖方违约不交货。法院判决卖方向买方双倍返还定金。
案例40：合同约定的违约金过高，违约方请求减少。法院根据实际损失酌情调低违约金。

# ==================== 五、民事诉讼程序（案例41-50） ====================
案例41：借款合同纠纷中，双方未约定管辖。法院认定应由被告住所地或者合同履行地人民法院管辖。
案例42：债权人超过三年未主张债权，债务人提出诉讼时效抗辩。法院认定诉讼请求已过诉讼时效，判决驳回诉讼请求。
案例43：诉讼中，当事人对自己提出的主张未能提供证据。法院依据“谁主张、谁举证”原则，判决其承担举证不能的不利后果。
案例44：被告经传票传唤，无正当理由拒不到庭。法院依法缺席判决。
案例45：案件诉讼标的额符合小额诉讼标准，法院适用小额诉讼程序，实行一审终审，当事人不得上诉。
案例46：债权人担心债务人转移财产，在起诉前申请财产保全。法院裁定查封、冻结债务人相应财产。
案例47：关键证据可能灭失，当事人申请证据保全。法院依法采取保全措施。
案例48：诉讼中一方当事人对另一方主张的于己不利的事实明确表示承认。法院依据自认规则对该事实予以认定，对方无需再举证。
案例49：微信聊天记录、转账记录等电子数据，经查证属实，可作为认定案件事实的证据。
案例50：当事人达成调解协议，共同向法院申请司法确认。法院审查后裁定调解协议有效，一方不履行的，另一方可申请强制执行。
